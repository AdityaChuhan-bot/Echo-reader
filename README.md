
# 📚 Echo Reader

> An AI-powered audiobook reader for Android that turns books into natural-sounding speech.

Echo Reader is designed for people who prefer listening instead of reading. Import books, documents, or PDFs and let the app read them aloud using high-quality offline AI text-to-speech.

---

## ✨ Features

* 📖 Read PDF, EPUB, TXT, and DOCX files
* 🎙️ High-quality AI Text-to-Speech
* 📱 Fully offline playback (after downloading voices)
* ⏯️ Play, Pause, Resume
* ⏩ Adjustable playback speed
* 📍 Automatic reading position memory
* 🌙 Dark Mode
* 📂 Local file library
* 🔍 Fast document import
* 💾 Offline-first design

## 📦 Installation

Clone the repository

```bash
git clone https://github.com/AdityaChuhan-bot/Echo-reader.git
```

Open the project in Android Studio and run it on an Android device with Android 8.0 (API 26) or newer.
